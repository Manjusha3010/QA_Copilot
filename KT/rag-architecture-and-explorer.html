Section 1 Full RAG diagram ? how this system is built

This QA Copilot implements a Modular RAG pipeline (as in The Testing Academy ? Modular RAG): separate modules for ingestion / indexing, query rewrite, routing, retrieval, reranking, and generation. Data lives in five Qdrant collections with dense (BGE-M3) and sparse (lexical) vectors; at query time Qdrant prefetches both branches and fuses with RRF before a cross-encoder reranker and Groq.

Indexing pipeline (offline)

Source files are chunked, embedded with BGE-M3 (dense + sparse), and upserted into the matching collection.

Section 2 RAG explorer (debugger)

Run a query against a live API. The explorer calls POST /api/rag/explore and shows which collections were routed, hits per collection, the rerank pool, final chunks sent to the LLM, the composed prompt (truncated if huge), and the model answer ? plus a plain-English list of pipeline steps so you can teach ?how the output came to be.?

Serve this page from the API host (recommended): start the backend, then open http://127.0.0.1:8843/kt/rag-architecture-and-explorer.html ? then you can leave ?API base URL? empty to use the same origin. If you open the file directly from disk, set the base URL explicitly (e.g. http://127.0.0.1:8843).

Section 3 Components used in this project

Each layer is swappable (Modular RAG): you can change models, add parsers, or extend retrieval without rewriting the whole stack.

Component Role Technology / location
API server HTTP routes for health, meta, paths, ingest, query, SSE chat, RAG explore; optional static UI. FastAPI ? backend/main.py, app.py
Vector database Stores chunk payloads + named dense and sparse vectors per collection. Qdrant ? backend/lib/qdrant_store.py
Embeddings Produces 1024-d dense vectors and lexical sparse weights for every chunk and query. FlagEmbedding BGEM3FlagModel ? backend/lib/embeddings.py
Hybrid retrieval Prefetch dense top-N and sparse top-N, fuse with RRF; fallback to dense-only if fusion fails. qdrant_client query_points + Fusion.RRF
Router Selects 1?2 collections per question (or user override / fallback to all). Groq JSON classifier ? backend/lib/router.py
Query rewrite Turns follow-up questions into standalone search queries using recent turns. Groq ? backend/lib/prompts.py
Reranker Cross-encoder scores query?passage pairs to reorder the merged pool. FlagEmbedding FlagReranker ? backend/lib/reranker.py
Generator Grounded answer with <doc> context and numeric citations. Groq chat completions ? backend/lib/retriever.py, prompts in prompts.py
Ingestion Walk repos / files, chunk, embed, upsert per collection. backend/ingest/*.py, backend/lib/chunking_*.py
RAG explorer Serializes the full retrieval trace for debugging and teaching. POST /api/rag/explore ? backend/lib/rag_explore.py + this HTML
Operator UI Chat, Status paths, reindex, RAG explorer (production co-pilot). React + Vite ? frontend/
