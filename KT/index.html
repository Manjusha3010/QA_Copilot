Quick start (two terminals)

Terminal 1 — API (from QACopilot folder):

.\.venv\Scripts\python.exe app.py

Terminal 2 — UI:

cd frontend
npm install
npm run dev

Then open http://127.0.0.1:5173/ (Chat · RAG Explorer · Status) or http://127.0.0.1:8843/kt/ (these KT pages).
